# 命令行里删文件，没有回收站

四个动作，构成命令行管理文件的基本盘：

| 动作 | Windows | macOS / Linux |
|---|---|---|
| 看有什么 | `dir` | `ls` |
| 复制 | `copy` | `cp` |
| 移动 / 改名 | `move` | `mv` |
| 删除 | `del` | `rm` |

前三个都还好，**第四个是唯一不可逆的**：`rm` 和 `del` 直接抹掉文件，不进回收站。没有「撤销」，没有「还原」。

危险的不是命令，是**通配符**。`rm *.txt` 里的 `*` 会匹配当前目录下所有 txt。敲之前你以为只有三个文件，实际可能有三十个。

所以有个几乎所有人都会用的习惯：**先列出来看，再删**。

```
ls *.txt      # 先看看匹配到哪些
rm *.txt      # 确认无误再执行
```

**今天能懂的一点**：命令行的威力来自「一条命令作用在一批文件上」，它的危险也来自同一处。按回车之前，先让命令告诉你它要动哪些文件。
