# 五个小工具接起来，比一个全能软件好用

命令行里最反直觉的一条设计：**每个程序只做一件事，做到极致**。

`ls` 只负责列文件，`find` 只负责找文件，`sort` 只负责排序。单独看都很弱。但它们之间可以用一根竖线连起来：

```
ls | sort | wc
```

这根竖线叫**管道**（`|`），意思是：把前一个命令的输出，直接当作后一个命令的输入。上面这条命令就是：列出文件 → 排序 → 数一数有几个。

同样的东西在图形界面里怎么做？打开文件夹、切到详细视图、点一下表头排序、再自己数。能做，但**不能重复**——明天换一个文件夹，你得再来一遍。

这里还有第二个符号：`>`，叫**重定向**，把输出写到文件里而不是屏幕上。

```
dir > 清单.txt
```

所以命令行真正的能力不是「快」，而是**把你的操作变成可以保存、可以再跑一遍的东西**。

**今天能懂的一点**：当你发现自己在重复做同一套「找文件、筛内容、复制粘贴」的动作时，问一句——有没有一条命令能替我做完全程。
