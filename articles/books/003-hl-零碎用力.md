# 电梯等在那儿，你走楼梯上去——每天攒够四分钟就够

下课回宿舍，电梯口排了七八个人。楼梯就在旁边，四层，你犹豫了三秒，还是站进队伍里。

「反正也不差这一分钟。」

英国生物银行跟踪了 2.52 万个平时完全不锻炼的人，平均 6.9 年，其中 852 人去世。研究里有一批人，每天有 3 次、每次 1–2 分钟的**零碎剧烈活动**——爬楼梯、快走赶路这种，不换衣服、不去健身房，就嵌在生活里。和完全没有的人比：

- 死亡风险、癌症死亡风险降低 **38%–40%**
- 心血管死亡风险降低 **48%–49%**

每天这类活动累计到 **4.4 分钟**的人，收益小一些但仍在：死亡和癌症死亡降 26%–30%，心血管死亡降 32%–34%。

注意研究对象——**平时完全不锻炼的人**。如果你已经有规律运动，这条对你不适用，别拿它当替代品。

也得说清它的局限：这是跟踪记录，没做分组试验，只跟了 6.9 年。好处是活动量靠可穿戴设备实测，不是让人回忆填问卷，比大多数同类研究可靠。

所以这条建议的成本接近零：不花钱，不占额外时间，**唯一的难点是记得**——电梯来了不进去，快递柜在楼下就走快两步。

四分钟，不是四十分钟。你缺的从来不是时间。
