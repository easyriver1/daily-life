# 第 2 期 · 你判断一段话是否可信，只需要四个问题

这周的六篇其实在讲同一件事：**别人怎么说服你，以及你怎么不被说服。**

## 本周都讲了什么

**书线三篇**（都来自《学会提问》）：

- **专家替代不了你**——你复述结论时，通常没带上依据
- **海绵式与淘金式**——接收信息和提问，可以同时进行
- **强势批判**——这套方法用来检查自己，比用来反驳别人难也值钱

**常识线两篇**：

- **电脑为什么越慢**——CPU / 内存 / 硬盘三者的速度差，决定了瓶颈在哪
- **什么是 API**——程序之间按约定交换数据，而不是"聊一句"

这两条线看着不搭，其实贴着：**一个是识别信息质量，一个是理解系统怎么运转。**

## 三十分钟任务包

**目标**：把本周的方法真正用一次。

挑一条你今天看到的、让你有点动摇的说法（广告、新闻、同学的推荐都行）。不要搜资料，只用四个问题过一遍：

1. 他到底想让我相信什么？（一句话写下来）
2. 他凭什么？（把理由列出来，不超过三条）
3. 哪一部分我最可能误解？（圈出一个词）
4. 有什么他没说？（至少写一条）

**做完的标准**：你能用三句话向别人复述这条信息的可靠程度，而不是只能复述内容。

## 本周闭卷自测

**不要查资料，先自己想，答案下周给。**

1. 「某地发生事故，5 人死亡」和「全球每年交通事故死亡约 119 万人」，为什么前者更让你难受？
2. 「发达国家 / 发展中国家」这个二分法，最大的问题是什么？
3. 电脑开机变慢、但用起来还不卡，最先该怀疑哪个部件？
4. 一个 API 至少要约定清楚哪三件事？
5. 为什么「批判性思维」用来检查自己比用来反驳别人更有价值？

答不上来不用慌——**答不上来的那一条，就是你这周真正需要重读的。**
