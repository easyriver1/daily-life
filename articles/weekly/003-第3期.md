# 第 3 期 · 你看到的曲线，可能只是整条 S 的最陡一段

这周的四篇在讲两件事：**怎么判断趋势**，以及**怎么判断一本书值不值得读**。

## 本周都讲了什么

**书线两篇**：

- **直线思维**——人看到两个点就会连成直线，但真实世界多是 S 形、钟形、趋平
- **阅读的三个层次**——速读判断值不值得读、精读弄懂一个论点、主题阅读解决一个问题

**常识线两篇**：

- **什么是算法**——同样一件事，换个做法能差几万倍；关键是「数据翻倍时工作量怎么变」
- **为什么负数用补码**——计算机只会加法，减法是靠"加一个绕回来的数"实现的

线是这么串起来的：**判断趋势需要数据，而读书是获取数据的入口；算法和补码则是「计算机为什么这样运转」的两块地基。**

## 三十分钟任务包

**目标**：把「速读」真正用一次。

挑一本你买来但没读完的书，定 20 分钟闹钟，只做四件事：

1. 读目录，圈出最相关的两章
2. 读序言，用一句话写下作者说自己要解决什么问题
3. 每章只读开头和结尾各一段
4. 合上书，回答：**这本书里值得精读的是哪一章？为什么**

**做完的标准**：你能说出"我暂时不读这本书，因为______"——这也是一个好答案。

## 本周闭卷自测

**不查资料，先自己想。**

1. 有人说「照这个速度，三年后就是十倍」，你最该问的一句话是什么？
2. 一本书 300 页，速读阶段你只读哪几部分？
3. 在一百万条数据里找一个值，顺序查找和对半查找各要多少次？为什么差这么多？
4. 8 位补码能表示的整数范围是多少？为什么负数比正数多一个？
5. 主题阅读的产出是什么？（提示：不是"读了五本书"）
