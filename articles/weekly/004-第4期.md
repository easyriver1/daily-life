# 第 4 期 · 你怕的东西，和真正危险的东西不是一回事

本周六篇围绕一个共同的问题：**你的直觉什么时候可靠，什么时候不可靠。**

## 本周都讲了什么

**书线三篇**：

- **阅读的三个层次**——速读判断值不值得读、精读弄懂一个论点、主题阅读解决一个问题
- **恐惧本能**——恐惧被「有画面、突发、有活物」触发，而现代主要死因全是缓慢无画面的
- **思考的障碍**——太快下结论、刻板印象代劳、一次只装一件事

**常识线两篇**：

- **什么是编译器**——预处理、编译、汇编、链接四步走，为什么 C 快 Python 慢
- **什么是缓存**——把常用的东西搬到更近的地方，难点是「什么时候该扔掉」

串起来是一条线：**人的直觉在原始环境里很准，在现代环境里经常错位；而计算机的设计，处处在替这种不可靠兜底（缓存是替代记忆，编译器是替代翻译）。**

## 三十分钟任务包

**目标**：把自己"怕的东西"和"真正的风险"对齐一次。

1. 写下三件你最近确实害怕的事（不要写新闻里的，写你自己的）
2. 每件后面写：它一年发生几次？在你这年龄段、你这环境里概率大概多少？
3. 再写三件你**不怕**、但每年杀死很多人的事（比如久坐、熬夜、不系安全带）

**做完的标准**：你能说出自己怕的三件事里，有几件是"因为画面"而不是"因为概率"。

## 本周闭卷自测

**不查资料，先自己想。**

1. 恐惧本能被哪四个条件触发？为什么现代主要死因很难触发它？
2. 编译的四个阶段分别是什么？"undefined reference" 属于哪一步的错误？
3. 缓存真正的难点是什么？列举两种失效策略。
4. 为什么「这本书很可靠，因为它说的都对」是循环论证？
5. 「减少作业量」被反驳成「你想让大家都别学了」，这叫什么？怎么识别？
