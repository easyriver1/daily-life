# 你现在双击的那个图标，其实就是一条命令

桌面上的 Chrome 图标，双击就能打开。命令行里敲一行字，也能打开同一个东西——差别只在于：**一个用鼠标指，一个用文字说**。

双击时系统做的事，其实是「按记录下来的路径启动这个程序」。命令行只是把这一步交给你自己写。

那为什么还要用它？因为鼠标只能做一件事一次，而文字可以**组合、记录、重复**：把三条命令接起来一次跑完，或者存成文件明天再跑一遍。这就是命令行真正的价值——不是更酷，是**能复用**。

Windows 上的「PowerShell」或「命令提示符」，macOS/Linux 上的「终端」，都是同一个东西的不同外壳。看到「在终端里执行」这句话，不用紧张，它只是换了个方式打开你已经会的程序。

**今天能懂的一点**：命令行不是程序员的黑话，它是「用文字操作系统」的入口，你已经在用它的图形版。
